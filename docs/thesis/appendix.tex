\section{Module Dependency Graph}
\label{app:module-graph}

The try-on processing path follows this module dependency chain:

\begin{lstlisting}[language={}, caption={Try-on module dependency graph}]
tryonController
  -> normalizeWebcamImage
  -> optimizePersonImageForReplicate
  -> createTryOnPrediction / runTryOnInference
       -> replicateService
            -> resolveExhibitionFinalImage
                 -> comfyTryOnService (optional L2)
                 -> tryOnSmartPoseOverlay (L3)
                      -> tryOnDemoComposite (L4)
                 -> tryOnFinalImageValidator
\end{lstlisting}

\section{Project Setup Instructions}
\label{app:setup}

\subsection{Backend Setup}

\begin{lstlisting}[language=bash, caption={Backend installation and startup}]
cd backend
cp .env.example .env
# Edit .env: set REPLICATE_API_TOKEN, MONGO_URI, etc.
npm install
npm start
\end{lstlisting}

\subsection{Frontend Setup}

\begin{lstlisting}[language=bash, caption={Frontend installation and startup}]
cd frontend
cp .env.example .env
# Edit .env: set VITE_API_BASE_URL=http://127.0.0.1:5000
npm install
npm run dev
\end{lstlisting}

\subsection{Production Build}

\begin{lstlisting}[language=bash, caption={Frontend production build}]
cd frontend
npm run build
npm run preview
\end{lstlisting}
